# DisplayScreen

LEVETOP serial front-panel display service.

| Directory | Platform |
|---|---|
| [ubuntu-screen-service](./ubuntu-screen-service/) | Ubuntu / systemd |
| [windows-screen-service](./windows-screen-service/) | Windows Service |

## Quick start

**Ubuntu**

```bash
cd ubuntu-screen-service
sudo ./INSTALL.sh
```

**Windows** (Administrator PowerShell)

```powershell
cd windows-screen-service
.\install.ps1
```
