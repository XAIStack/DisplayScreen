# displayshow Windows 部署手册（中文）

前面板 LEVETOP 串口屏服务：主机采集系统状态，经 USB 串口写入屏幕，并以 **Windows 服务**（`DisplayScreen`）开机自启。

| 项 | 值 |
|---|---|
| 版本 | **1.1.1** |
| 默认安装目录 | `%ProgramData%\displayshow`（通常为 `C:\ProgramData\displayshow`） |
| Windows 服务名 | `DisplayScreen` |
| 适用系统 | Windows 10 / 11 / Server 2019+（x64） |

英文版：[DEPLOYMENT.en.md](./DEPLOYMENT.en.md)

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 及以上 |
| Python | 3.9+，安装时勾选 **Add python.exe to PATH** |
| 权限 | 管理员（安装服务、访问串口） |
| 硬件 | 前面板串口屏（USB 转串口，常见 `COM3`，115200 8N1）；灯带可选（常见 `COM4`） |
| 可选 | NVIDIA 驱动（`nvidia-smi`，独显温度/占用）；LibreHardwareMonitor（更准确的 CPU 温度） |

## 3. 安装步骤

### 3.1 安装 Python

从 [python.org](https://www.python.org/downloads/) 安装 3.9+，勾选 **Add python.exe to PATH**。

验证：

```powershell
python --version
```

### 3.2 确认串口

设备管理器 → 端口 (COM 和 LPT)，记录屏幕与灯带对应的 COM 号。

或在 PowerShell：

```powershell
[System.IO.Ports.SerialPort]::GetPortNames()
# 或
Get-CimInstance Win32_SerialPort | Select-Object DeviceID, Name
```

常见对应（以本机为准）：

- 屏幕：`COM3`
- 灯带：`COM4`

将 `config.json` 中的 `serial_port` / `led_serial_port` 改成实际口。

### 3.3 一键安装（管理员 PowerShell）

```powershell
cd windows-screen-service
# 若脚本被禁止执行：
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

安装会：

1. 复制程序到 `%ProgramData%\displayshow`
2. 创建 `.venv` 并安装 `pyserial`、`psutil`、`pywin32`
3. 注册并启动 Windows 服务 `DisplayScreen`（开机自启）

指定目录 / 覆盖配置：

```powershell
.\install.ps1 -InstallDir "C:\displayshow"
.\install.ps1 -ForceConfig
```

## 4. 验证

```powershell
Get-Service DisplayScreen
# Status 应为 Running

# 前台干跑（不写串口）
& "$env:ProgramData\displayshow\.venv\Scripts\python.exe" -u "$env:ProgramData\displayshow\screen_updater.py" --dry-run --once
```

或：

```powershell
cd $env:ProgramData\displayshow
.\run_screen_updater.bat --dry-run --once
```

成功时屏上第 4 页应显示本机网口 IP；日志可在 **事件查看器 → Windows 日志 → 应用程序** 中查看（Python Service）。

## 5. 日常运维

```powershell
Get-Service DisplayScreen
Restart-Service DisplayScreen
Stop-Service DisplayScreen
Start-Service DisplayScreen
```

修改 `config.json` 后必须重启服务：

```powershell
Restart-Service DisplayScreen
```

背光测试：

```powershell
cd $env:ProgramData\displayshow
.\run_screen_updater.bat --blank
.\run_screen_updater.bat --unblank
```

## 8. 配置说明

文件：`%ProgramData%\displayshow\config.json`

### 8.1 串口

| 项 | 默认 | 说明 |
|---|---|---|
| `serial_port` / `serial_ports` | `COM3` | 屏幕口，探测顺序 |
| `led_serial_port` | `COM4` | 灯带；屏口探测会跳过它 |
| `baudrate` | `115200` | 与屏工程一致 |

COM10 及以上会自动写成 `\\.\COMx` 形式。

### 8.2 网口 IP

| 项 | 默认 | 说明 |
|---|---|---|
| `net_iface_auto` | `true` | 自动选取物理以太网适配器 |
| `net_ip_wait_seconds` | `8` | 开机等待拿到 IPv4 的秒数 |
| `net1_iface` / `net2_iface` | 空 | 仅当 `net_iface_auto` 为 `false` 时使用 |

固定网卡示例（名称与「网络连接」中一致）：

```json
"net_iface_auto": false,
"net1_iface": "以太网",
"net2_iface": "Ethernet 2"
```

### 8.3 切页与刷新

| 项 | 说明 |
|---|---|
| `page_cycle` | 页号与停留秒数（默认 4→5→6→7→8→9） |
| `refresh_interval_seconds` | 总览刷新周期，默认 60 |

## 9. Windows 服务说明

| 项 | 值 |
|---|---|
| 服务名 | `DisplayScreen` |
| 显示名 | LEVETOP Front Panel Display (displayshow) |
| 启动类型 | Automatic |
| 实现 | `win_service.py` + pywin32 |

手动注册（一般用 `install.ps1` 即可）：

```powershell
cd $env:ProgramData\displayshow
.\.venv\Scripts\python.exe win_service.py --startup auto install
Start-Service DisplayScreen
```

## 10. 与 Linux 版差异

| 项 | Windows | Linux |
|---|---|---|
| 串口 | `COMx` | `/dev/ttyUSB*` |
| 服务 | Windows Service | systemd |
| CPU 温度 | LibreHardwareMonitor / ACPI | `coretemp` hwmon |
| 磁盘槽位 | `Get-PhysicalDisk` 顺序映射 | PCIe / ATA 口映射 |
| 安装目录 | `%ProgramData%\displayshow` | `/opt/displayshow` |

屏端协议与控件地址与 Linux 版相同。

## 11. 排障

| 现象 | 处理 |
|---|---|
| 服务起不来 | `Get-Service DisplayScreen`；事件查看器 Application 日志 |
| 无 ACK / 屏不动 | COM 口号错误、被其它程序占用、波特率不对 |
| `Access denied` 打开串口 | 用管理员安装服务；关闭占用该口的串口助手 |
| IP 为 `0.0.0.0` | 网线未插或未获地址；`ipconfig` / `Get-NetIPAddress` |
| 温度一直为 0 | 安装并运行 LibreHardwareMonitor（开启 WMI）；或接受 ACPI 近似值 |
| `pywin32` 安装失败 | 确认 64 位 Python；重跑 `install.ps1` |
| 脚本无法运行 | `Set-ExecutionPolicy -Scope Process Bypass` |

列出 COM 口：

```powershell
python -c "import serial.tools.list_ports as lp; print([p.device for p in lp.comports()])"
```
