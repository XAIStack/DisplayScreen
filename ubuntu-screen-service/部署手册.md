# displayshow 部署手册（中文）

前面板 LEVETOP 串口屏服务：主机采集系统状态，经 USB 串口写入屏幕，并以 systemd 开机自启。

| 项 | 值 |
|---|---|
| 版本 | **1.1.1** |
| 安装目录 | `/opt/displayshow` |
| systemd 服务 | `display-screen.service` |
| 适用系统 | Ubuntu 20.04+ / Debian / 其它 systemd Linux |

英文版：[DEPLOYMENT.en.md](./DEPLOYMENT.en.md)

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Ubuntu（或其它带 systemd 的 Linux） |
| Python | 3.9+，需 `python3-venv`、`python3-pip` |
| 权限 | root（写 `/opt`、安装单元、访问串口） |
| 硬件 | 前面板串口屏（常见 `/dev/ttyUSB1`，115200 8N1）；灯带可选（`/dev/ttyUSB0`） |
| 用户组 | 运行用户需能访问串口（通常为 `dialout`） |

网口 IP 默认按板载网卡自动识别，换机器一般不用改网口名。

## 2. 包内文件

```text
ubuntu-screen-service/
  INSTALL.sh                 # 一键安装
  deploy.sh                  # 创建 venv、启用 systemd
  wait_serial.sh             # 开机等待 USB 串口
  display-screen.service     # systemd 单元模板
  screen_updater.py          # 主程序
  system_metrics.py          # 指标采集
  levetop_protocol.py        # 串口屏协议
  config.json                # 串口 / 地址 / 切页
  requirements.txt           # pyserial、psutil
  run_screen_updater.sh|.py  # 手动启动辅助
  部署手册.md                # 本文（中文）
  DEPLOYMENT.en.md           # English guide
  VERSION
```

安装包不含 `.venv`，由目标机上的 `deploy.sh` 自动创建。

---

## 3. 安装步骤

### 3.1 安装系统依赖

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv python3-pip
```

### 3.2 确认串口

```bash
ls -l /dev/ttyUSB* /dev/serial/by-id
```

常见对应：

- `/dev/ttyUSB1`：屏幕
- `/dev/ttyUSB0`：灯带（不要把屏程序指到灯带口）

### 3.3 一键安装

```bash
cd ubuntu-screen-service
sudo ./INSTALL.sh
```

默认安装到 `/opt/displayshow`，并执行：

1. 复制程序文件  
2. 创建 Python 虚拟环境，安装 `pyserial`、`psutil`  
3. 安装 `/etc/systemd/system/display-screen.service`  
4. `systemctl enable --now display-screen.service`

指定目录：

```bash
sudo PREFIX=/opt/displayshow ./INSTALL.sh
```

用包内配置覆盖已有 `config.json`：

```bash
sudo ./INSTALL.sh --force-config
```

## 4. 验证

```bash
systemctl is-enabled display-screen.service   # 应为 enabled
systemctl status display-screen.service
journalctl -u display-screen.service -n 50 --no-pager
```

成功时日志类似：

```text
Opened /dev/ttyUSB1 @ 115200 baud
NIC auto=True discovered=enp86s0,enp87s0 -> net1=enp86s0 net2=enp87s0
net1_ip@0x1116=10.x.x.x (...)
  <- ACK OK (CRC passed)
```

屏上第 4 页应显示本机网口 IP。只有一块网卡在线时，另一路为 `0.0.0.0` 属正常。

干跑（不写串口）：

```bash
sudo /opt/displayshow/.venv/bin/python -u /opt/displayshow/screen_updater.py --dry-run --once
```

## 5. 日常运维

```bash
sudo systemctl status display-screen.service
sudo systemctl restart display-screen.service
sudo systemctl stop display-screen.service
sudo journalctl -u display-screen.service -f

sudo /opt/displayshow/deploy.sh status
sudo /opt/displayshow/deploy.sh restart
```

修改 `config.json` 后必须重启服务：

```bash
sudo systemctl restart display-screen.service
```

背光测试：

```bash
sudo /opt/displayshow/.venv/bin/python -u /opt/displayshow/screen_updater.py --blank
sudo /opt/displayshow/.venv/bin/python -u /opt/displayshow/screen_updater.py --unblank
```

## 6. 升级

在新版本目录执行：

```bash
sudo ./INSTALL.sh
```

**默认保留**目标机已有的 `/opt/displayshow/config.json`。若要用包内默认配置覆盖：

```bash
sudo ./INSTALL.sh --force-config
```

## 7. 卸载

只去掉开机服务（程序文件仍保留）：

```bash
sudo ./INSTALL.sh uninstall
# 或
sudo /opt/displayshow/deploy.sh uninstall
```

连程序一起删除：

```bash
sudo /opt/displayshow/deploy.sh uninstall
sudo rm -rf /opt/displayshow
```

## 8. 配置说明

文件：`/opt/displayshow/config.json`

### 8.1 串口

| 项 | 默认 | 说明 |
|---|---|---|
| `serial_port` / `serial_ports` | `/dev/ttyUSB1` | 屏幕口，探测顺序 |
| `led_serial_port` | `/dev/ttyUSB0` | 灯带；屏口探测会跳过它 |
| `baudrate` | `115200` | 与屏工程一致 |

若本机屏在 `ttyUSB0`，对调这两项后再 `restart`。

### 8.2 网口 IP

| 项 | 默认 | 说明 |
|---|---|---|
| `net_iface_auto` | `true` | 按板载网卡 PCI 顺序自动对应屏上网口 1/2 |
| `net_ip_wait_seconds` | `8` | 开机等待 DHCP 的最长时间（秒） |
| `net1_iface` / `net2_iface` | 空 | 仅当 `net_iface_auto` 为 `false` 时使用 |

固定某块网卡示例：

```json
"net_iface_auto": false,
"net1_iface": "enp86s0",
"net2_iface": "enp87s0"
```

### 8.3 切页与刷新

| 项 | 说明 |
|---|---|
| `page_cycle` | 页号与停留秒数（默认 4→5→6→7→8→9） |
| `refresh_interval_seconds` | 总览与全页预写周期，默认 60 |

### 8.4 磁盘图标（第 9 页）

`ssd_slot_pci_roots` 按机型 PCIe 槽位填写。换主板时 SSD 顺序可能需要对齐。未列出的 NVMe 会填到剩余空槽。

## 9. systemd 单元

安装后路径：`/etc/systemd/system/display-screen.service`

```ini
[Unit]
Description=LEVETOP serial front-panel display (displayshow)
After=local-fs.target network-online.target systemd-udev-settle.service
Wants=network-online.target
StartLimitIntervalSec=0

[Service]
Type=simple
WorkingDirectory=/opt/displayshow
Environment=PYTHONUNBUFFERED=1
ExecStartPre=/opt/displayshow/wait_serial.sh
ExecStart=/opt/displayshow/.venv/bin/python -u /opt/displayshow/screen_updater.py
Restart=always
RestartSec=5
TimeoutStopSec=30
KillSignal=SIGTERM
SupplementaryGroups=dialout
StandardOutput=journal
StandardError=journal
SyslogIdentifier=display-screen

[Install]
WantedBy=multi-user.target
```

`INSTALL.sh` 会执行 `systemctl enable`，进入多用户模式即启动，无需 `rc.local` 或 crontab。

## 10. 排障

| 现象 | 处理 |
|---|---|
| 服务起不来 | `journalctl -u display-screen.service -n 80 --no-pager` |
| 屏无变化、日志无 ACK | 口选错（USB0/USB1 对调）、波特率、权限（`dialout`） |
| IP 为 `0.0.0.0` | 该口未插线或未拿到地址；确认 `ip -br addr` |
| IP 仍是旧网口名 | 确认 `net_iface_auto` 为 `true`，然后 `restart` |
| 温度一直 42 | 误读 ACPI `acpitz`，或字符地址/类型不对 |
| 开机前几秒没有屏 | USB 枚举慢，`wait_serial.sh` 最多等 20 秒，属正常 |
| `python3-venv` / pip 失败 | 安装 `python3-venv python3-pip` 后重跑 `INSTALL.sh` |
| 权限拒绝 | `sudo usermod -aG dialout $USER`，重新登录 |
| `restart` 卡住十几秒 | 串口占用，单元 `TimeoutStopSec=30`，等结束后会拉起新进程 |

查看本机网卡：

```bash
ip -br addr
ls -l /sys/class/net/
```

## 11. 页面说明（摘要）

| 页 | 停留 | 内容 |
|---|---|---|
| 4 | 10 s | 总览：时钟、网口 IP、健康度、网络状态 |
| 5 | 2 s | CPU 使用率、温度、温度进度条 |
| 6 | 2 s | GPU 使用率、温度、温度进度条 |
| 7 | 2 s | 内存占用、容量、电量（固定 0） |
| 8 | 2 s | 存储占用、网络速率 |
| 9 | 2 s | M.2 SSD ×4 + 机械盘 ×6 状态图标 |
